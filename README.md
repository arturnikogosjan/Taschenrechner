# Taschenrechner – Webentwicklungsprojekt

## Projektbeschreibung
Ein webbasierter Taschenrechner mit einem übersichtlichen, modernen Design. Die Anwendung ermöglicht grundlegende mathematische Berechnungen direkt im Browser.

## Funktionen
- Zahlen und Rechenoperationen eingeben
- Addition, Subtraktion, Multiplikation und Division
- Dezimalzahlen verwenden
- Eingaben löschen oder korrigieren
